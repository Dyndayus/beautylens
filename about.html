Tentang BeautyLens

Deskripsi Tugas & Sistem

BeautyLens merupakan aplikasi web berbasis kecerdasan buatan (Computer Vision) yang dikembangkan untuk mengklasifikasikan produk makeup ke dalam tiga kategori utama, yaitu Bedak, Brush, dan Lippies.

Model dilatih menggunakan algoritma Convolutional Neural Network (CNN) pada 1.500 citra, lalu dikonversi ke format ONNX agar dapat melakukan deteksi secara cepat dan real-time langsung di web tanpa memerlukan server komputasi tambahan.
